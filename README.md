## Как читать таблицу

Одна строка — один прогон. Год в ячейке «Лицо» не пишется: это ноябрь 2026.

| Колонка | Значение |
|---|---|
| Лицо | Время на квитанции, как оно записано в сводке. |
| Квитанция | Номер на лице. Прочерк — номер в этой строке не записан. |
| Serena | ✅ прошла, ❌ не прошла, прочерк — на Serena файл не отправляли. |
| Trexo | То же для Trexo. |
| Файл | PDF в `чеки с валидаторов`, в подпапке с тем же именем, что у таблицы. Прочерк — файла в этой поставке нет. |
